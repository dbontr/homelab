# Eminence skills

Four portable, standalone instruction sets live under this directory. Each includes a `SKILL.md` entrypoint and ChatGPT UI metadata in `agents/openai.yaml`. The files are portable source packages: GitHub storage alone does **not** install them into a ChatGPT account.

| Skill | Purpose |
| --- | --- |
| [Development](development/SKILL.md) | Production coding, repository hygiene, GitHub workflows, multi-repository project orchestration, source verification and independent release governance |
| [Writing](writing/SKILL.md) | Scholarly and practical drafting, editing, source integrity, argument and rhetorical quality |
| [Teaching](teaching/SKILL.md) | Prerequisite-based, first-principles instruction, difficult transfer problems and evidence-backed mastery |
| [Ideas](ideas/SKILL.md) | Interdisciplinary hypothesis generation, prior-art criticism and falsifiable experiments |

Eminence may expose these to an assistant through a supported skill installation or an explicit project-owned tool interface. An installed skill governs the assistant's *method*; it does not itself grant data, repository, server, cloud or administrative permissions. Such authority remains with the user's connected services, project grants and independent executor.

The skill definitions favor evidence of actual user achievement over engagement metrics. The [governing philosophy](../docs/philosophy.md) defines the outcomes that improvements should serve.
